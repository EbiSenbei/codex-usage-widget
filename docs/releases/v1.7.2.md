# Agent Usage Widget 1.7.2

## 修正

- 「常に最前面に表示」が有効でも、タスクバーやシステムトレイから開いたウィジェットが、他のアプリをクリックすると消える不具合を修正しました。
- 設定が有効な間は、他のアプリに切り替えてもウィジェットの表示を維持します。設定が無効な場合の自動非表示、タスクバー表示のクリックによる開閉、`−` ボタンによる非表示は従来どおりです。

## インストール・更新

1. `agent-usage-widget-win-x64.zip` をダウンロードして展開します。
2. 起動中の旧バージョンを終了し、展開先の `AgentUsageWidget.exe` を起動します。

.NET ランタイムは同梱されています。既存の設定は引き継がれます。
ZIP の SHA-256 は、添付の `agent-usage-widget-win-x64.zip.sha256` で確認できます。

## 検証

- Release ビルドと全 251 件の自動テストが成功しました。
- 修正前の非表示処理を再現し、修正後の最前面設定のオン・オフと明示的な非表示操作を確認しました。
- Windows の実画面でのクリック操作による確認は未実施です。
